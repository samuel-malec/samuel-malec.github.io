This is an educational compiler built in order to demonstrate the core ideas in compiler theory.
It is aimed to target a small language that would be expressive enough, so that we can write more useful programs. 
The source code is on [github](https://github.com/samuel-malec/compiler-dungeon).
I am planning to do some technical write-ups on the topics I am dealing with while working on this project. 
In the meantime, I wanted to create an interactive IR visualizer that would depict the different representations of a program during the compilation pipeline.
You can check the language overview [here](https://github.com/samuel-malec/compiler-dungeon/blob/main/docs/language.md)
and you can try it out for yourself below:

    if a < b {
        b
    } else {
        a
    }
}
`} />

## Optimizations

Toggle SCCP (Sparse Conditional Constant Propagation) and dead code elimination on and off to see how they interact. SCCP folds constant arithmetic, resolves branches whose condition it can prove at compile time, and deletes the blocks that become unreachable as a result — which is exactly what leaves behind dead computations for DCE to sweep up.

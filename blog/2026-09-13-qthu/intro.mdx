# Dagon 🐙

import QthuExplorer from '@site/src/components/QthuExplorer';

Dagon is a compiler toolchain that takes a subset of JavaScript all the way down to real QuickJS bytecode, through a small, intermediate language called Cthulhu.
The source code is on [github](https://github.com/samuel-malec/qthu).

Two compilers make up the pipeline: `js2ct` lowers JavaScript into Cthulhu IR (`.ct` text), and `ct2qjs` lowers Cthulhu IR into QuickJS bytecode. Below, both run together in your browser, compiled to WebAssembly — and the resulting bytecode is actually *executed* against an embedded QuickJS runtime, not just displayed. Edit the source and every tab updates live; the banner under the editor shows what really happened when the program ran, `assert` failures included.

<QthuExplorer defaultSource={`function fib_rec(fib1, fib2, n) {
    if (n == 0) {
        return fib2;
    }
    return fib_rec(fib2, fib1 + fib2, n - 1);
}

function fib_base(n) {
    if (n <= 2) {
        return 1;
    }
    return fib_rec(1, 1, n - 2);
}

assert( fib_base( 1 ) == 1 );
assert( fib_base( 2 ) == 1 );
assert( fib_base( 3 ) == 2 );
assert( fib_base( 4 ) == 3 );
assert( fib_base( 5 ) == 5 );
`} />

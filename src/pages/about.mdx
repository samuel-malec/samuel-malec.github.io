# About

I'm a compiler and static-analysis enthusiast based in Brno. I'm a Master's student in Theoretical Computer Science at Masaryk University, and I also work as a student researcher on an abstract interpretation framework inside GraalVM Native Image, which grew out of my bachelor's thesis. My main language is C++, and I like the parts of a compiler that sit between the source language and the machine: intermediate representations, SSA, dataflow and fixpoint analyses.

I also teach first-year students Python and C, which has made me a lot more careful about how I explain things. On the side I build [Compiler Dungeon](/projects/compiler-dungeon), an educational compiler, and write about it on my [blog](https://samuel-malec.github.io). Away from the keyboard I like to be active, whether it is hiking, biking, or running.

## Education

- **MSc, Theoretical Computer Science**, Masaryk University, Brno — 2025–2027. Thesis (in progress): compiler intermediate representations.
- **BSc, Programming and Development**, Masaryk University, Brno — thesis *A Framework for Abstract Interpretation in the GraalVM Native Image Java Compiler* (2025).

## Experience

- **Junior Researcher, AVELAB, Faculty of Informatics, Masaryk University** — 2024–present. Building GraalAIF, an abstract interpretation framework inside GraalVM Native Image, in collaboration with Oracle Labs. It runs on Graal IR after the points-to analysis, with interval, pentagon and resource-leak analyses on top.
- **Seminar Tutor, Faculty of Informatics, Masaryk University** — introductory [Python](https://is.muni.cz/predmet/fi/podzim2026/IB111) and [C](https://is.muni.cz/predmet/fi/jaro2027/PB111) courses.
- **C++ Developer, SANEZOO** — April 2024–January 2025. Built tooling for industrial protocols (OPC UA, Step7, Modbus) and a config-file compiler for microservice orchestration.
